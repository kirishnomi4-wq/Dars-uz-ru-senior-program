# 🏠 LMS-PAKET — PracticeLesson3 (M2-11) · savol-turi: Text

> Rasm shart emas (yozma reja — dekompozitsiya, kod emas).

---

## `uz` · Matn

```
Arxitektor bo'ling — AI'ni ochishdan oldin o'z loyihangizni bo'laklang. To'rtala topshiriqqa yozma javob bering:

1. Bitta o'z g'oyangizni bir gap bilan yozing (masalan: sinf uchun kutubxona-sayt).
2. Uni kamida 5 bo'lakka bo'ling — har bo'lak alohida qatorda.
3. Har bo'lak yoniga belgi qo'ying: MVP (shart) yoki KEYIN. MVP'da 2–3 bo'lak bo'lsin.
4. MVP bo'laklarini qurilish tartibida yozing: nimadan boshlanadi (poydevor), nima keyin.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining dekompozitsiya uy vazifasini tekshiryapsiz. 4 topshiriq: g'oya, bo'laklar, MVP/KEYIN belgisi, qurilish tartibi.

Qabul mezonlari:
1) g'oya bir gapda va o'ziniki (darsdagi maktab do'konining nusxasi emas);
2) kamida 5 bo'lak bor, har biri alohida aniq narsa (takror emas);
3) MVP'da 2–3 bo'lak va ular haqiqatan yadro — MVP'siz loyiha umuman ishlamaydi; bezak-bo'laklar KEYIN'da;
4) MVP tartibi mantiqiy: poydevor (asosiy ma'lumot/ro'yxat) birinchi, ko'rinish-bezagi oxirida.

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- MVP katta bo'lsa — darsdagi qoidani eslating: «eng kichik, lekin ishlaydigan versiya». Qaysi bo'lak KEYIN'ga o'tishini o'quvchi o'zi tanlasin — siz sanab bermang.
- Tartib xato bo'lsa, oqibatini bir misol bilan ko'rsating (poydevorsiz bezak — havoda turgan devor), to'g'ri tartibni yozib bermang.
- G'oya tanloviga baho bermang — g'oya o'quvchiniki.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: reja tayyor, endi AI'ni ochsa bo'ladi.
```

## `ru` · Matn

```
Побудьте архитектором — прежде чем открывать AI, разбейте свой проект на части. Письменно выполните четыре задания:

1. Запишите одну свою идею одной фразой (например: сайт-библиотека для класса).
2. Разбейте её минимум на 5 частей — каждая часть на отдельной строке.
3. Поставьте рядом с каждой частью метку: MVP (обязательно) или ПОТОМ. В MVP пусть будет 2–3 части.
4. Запишите части MVP в порядке стройки: с чего начинается (фундамент), что потом.
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по декомпозиции ученика 13 лет. 4 задания: идея, части, метки MVP/ПОТОМ, порядок стройки.

Критерии приёма:
1) идея в одной фразе и собственная (не копия школьного магазина из урока);
2) минимум 5 частей, каждая — отдельная конкретная вещь (без повторов);
3) в MVP 2–3 части, и они действительно ядро — без MVP проект вообще не работает; украшения — в ПОТОМ;
4) порядок MVP логичен: фундамент (основные данные/список) первым, оформление — в конце.

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если MVP раздут — напомните правило из урока: «самая маленькая, но работающая версия». Какую часть перенести в ПОТОМ, ученик выбирает сам — не перечисляйте за него.
- Если порядок нарушен — покажите последствие одним примером (украшение без фундамента — стена в воздухе), правильный порядок не выписывайте.
- Выбор идеи не оценивайте — идея принадлежит ученику.
- Если всё в порядке — похвалите одной фразой: план готов, теперь можно открывать AI.
```
