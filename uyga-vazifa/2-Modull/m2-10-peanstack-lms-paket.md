# 🏠 LMS-PAKET — PeanStackLesson (M2-10) · savol-turi: Text

> Rasm shart emas (yozma tahlil — darsning «detektiv» uy-vazifa ekrani bilan bir chiziqda).

---

## `uz` · Matn

```
Detektiv bo'ling — har kuni ishlatadigan ilovalaringizning ichiga qarab, uchala savolga o'z so'zlaringiz bilan yozma javob bering:

1. YouTube: frontend (zal) sizga nimani ko'rsatadi, backend (oshxona) nimani saqlaydi? 2–3 gap yozing.
2. Telegram: xabaringiz telefoningizda emas — qayerda saqlanadi? Javobingiz + nima uchun shunday, 1–2 gap.
3. O'z saytingiz: unga PERN jamoasining qaysi a'zolari yetishmayapti? Nomlarini yozing va bittasi nima ish qilishini ayting.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining «PERN Stack» darsi bo'yicha yozma javoblarini tekshiryapsiz. 3 savol: YouTube, Telegram, o'z sayti.

Qabul mezonlari:
1) YouTube'da frontend/backend to'g'ri ajratilgan: ko'rinadigan qism (video oynasi, tugmalar) va saqlanadigan qism (videolar, izohlar, obunalar) — so'zma-so'z shart emas, ma'no bo'lsa yetadi;
2) Telegram javobida xabar serverda (bazada) saqlanishi va sababi bor (masalan: telefon almashsa ham xabarlar turadi);
3) o'z sayti haqida to'g'ri xulosa: hozircha faqat frontend bor — kamida 2 ta yetishmayotgan a'zo nomlangan (Express, Node.js, PostgreSQL) va bittasining ishi aytilgan.

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Qaysi savol chala ekanini aniq ayting.
- Restoran metaforasida (zal, oshxona, ofitsiant, ombor) tushuntirilgan javob to'liq qabul.
- Darslikdan ko'chirilgan quruq ta'rif javob emas — juda kitobiy bo'lsa, o'zi kuzatgan misol bilan yozishga qaytaring.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: endi ilovalarning ichini ko'ra oladi.
```

## `ru` · Matn

```
Побудьте детективом — загляните внутрь приложений, которыми пользуетесь каждый день, и письменно ответьте своими словами на три вопроса:

1. YouTube: что вам показывает frontend (зал), а что хранит backend (кухня)? Напишите 2–3 фразы.
2. Telegram: ваше сообщение хранится не в телефоне — а где? Ваш ответ + почему так, 1–2 фразы.
3. Ваш сайт: каких участников команды PERN ему не хватает? Назовите их и скажите, чем занимается один из них.
```

## `ru` · AI prompt

```
Вы проверяете письменные ответы ученика 13 лет по уроку «PERN Stack». 3 вопроса: YouTube, Telegram, свой сайт.

Критерии приёма:
1) в ответе про YouTube верно разделены frontend/backend: видимая часть (окно видео, кнопки) и хранимая часть (видео, комментарии, подписки) — не дословно, достаточно смысла;
2) в ответе про Telegram сказано, что сообщение хранится на сервере (в базе), и есть причина (например: смените телефон — сообщения останутся);
3) про свой сайт верный вывод: пока есть только frontend — названы минимум 2 недостающих участника (Express, Node.js, PostgreSQL) и работа одного из них.

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Точно называйте, какой вопрос недоделан.
- Ответ через метафору ресторана (зал, кухня, официант, склад) полностью принимается.
- Вместо сухого определения из учебника нужно собственное наблюдение — слишком книжный текст верните с просьбой «своими словами».
- Если всё в порядке — похвалите одной фразой: теперь ученик видит приложения изнутри.
```
