# 🏠 LMS-PAKET — CiCdIntroLesson (M4C-01) · savol-turi: Text

> Rasm shart emas (yozma kuzatuv — darsning o'z kapsulasi: sanang · tartib · o'qing).

---

## `uz` · Matn

```
Lentangizni rejalashtiring — uchala topshiriqqa yozma javob bering:

1. Sanang: o'z loyihangizda deploy hozir nechta QO'LDA qadamdan iborat? Qadamlarni birma-bir yozing.
2. Tartib: lenta 5 nuqtasini yoddan to'g'ri tartibda yozing — har nuqta yonida buyrug'i bilan (yig'ish, skaner, o'lcham ramkasi, o'rash, uchirish).
3. O'qing: GitHub Actions haqida qisqa material ko'rib, bir gap yozing — darsda eshitmagan bitta yangi narsangiz.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining CI/CD uy vazifasini tekshiryapsiz. 3 topshiriq: qo'lda-qadamlar, 5 nuqta tartibi, o'qish-kuzatuvi.

Qabul mezonlari:
1) qo'lda qadamlar sanab yozilgan (kamida 3 qadam — test, build, yuklash kabi);
2) 5 nuqta to'g'ri tartibda va buyruqlari bilan: Yig'ish (npm install) → Skaner (npm test) → O'lcham ramkasi (eslint) → O'rash (npm run build) → Uchirish (deploy);
3) o'qish-kuzatuvida darsdan tashqari bitta ANIQ narsa bor (umumiy «foydali ekan» emas).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Uchirish Skanerdan oldin turgan bo'lsa — darsdagi oqibatni eslating: tekshirilmagan yuk samolyotga chiqib ketadi; to'g'ri tartibni yozib bermang.
- Nuqta nomi esdan chiqqan bo'lsa — aeroport-lentasini eslating.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: keyingi darsda shu lentani o'zi yozadi.
```

## `ru` · Matn

```
Спланируйте свою ленту — письменно выполните три задания:

1. Посчитайте: из скольких РУЧНЫХ шагов сейчас состоит деплой вашего проекта? Запишите шаги по одному.
2. Порядок: по памяти запишите 5 точек ленты в верном порядке — рядом с каждой — её команду (сборка, сканер, рамка размера, упаковка, взлёт).
3. Почитайте: посмотрите короткий материал о GitHub Actions и запишите одну фразу — одну новую вещь, которой не было на уроке.
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по CI/CD ученика 13 лет. 3 задания: ручные шаги, порядок 5 точек, наблюдение из чтения.

Критерии приёма:
1) ручные шаги перечислены (минимум 3 — тест, сборка, загрузка);
2) 5 точек в верном порядке с командами: Сборка (npm install) → Сканер (npm test) → Рамка размера (eslint) → Упаковка (npm run build) → Взлёт (deploy);
3) в наблюдении есть одна КОНКРЕТНАЯ вещь сверх урока (не общее «полезно»).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если Взлёт стоит раньше Сканера — напомните последствие из урока: непроверенный груз улетит в самолёт; верный порядок не выписывайте.
- Если имя точки забыто — напомните ленту аэропорта.
- Если всё в порядке — похвалите одной фразой: на следующем уроке он напишет эту ленту сам.
```
