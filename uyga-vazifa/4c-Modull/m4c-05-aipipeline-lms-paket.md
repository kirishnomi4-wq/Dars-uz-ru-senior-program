# 🏠 LMS-PAKET — AiPipelineProjectLesson (M4C-05) · savol-turi: Text

> Rasm shart emas (yozma sikl-hisobot — darsning o'z kapsulasi: sinang · tekshiring · yozing).

---

## `uz` · Matn

```
Yordamchi bilan to'rt qadamni o'z loyihangizda o'tang — uchala topshiriqqa yozma javob bering:

1. Sinang: loyihangizda bitta xato chiqaring (yoki mavjudini oling) va yordamchidan (Antigravity yoki boshqa AI) ANIQ so'rov bilan yordam so'rang. So'rovingizni to'liq yozing — darsdagi qolip: fayl + qator + kutildi/keldi.
2. Tekshiring: yordamchi taklifini jurnal yoki xato-xabari bilan solishtirganingizni yozing — mos keldimi, keyin qabul qildingizmi.
3. Yozing: yordamchi qaysi holatlarda adashishi mumkin — o'zingizga 2–3 misolli eslatma.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining AI-yordamchi uy vazifasini tekshiryapsiz. 3 topshiriq: aniq so'rov, tekshirish, eslatma.

Qabul mezonlari:
1) so'rov darsdagi qolipda: fayl nomi + qator (yoki aniq joy) + kutilgan va kelgan qiymat — «ishlamayapti, nima qildim?» kabi loyqa so'rov o'tmaydi;
2) tekshirish bayonida taklif jurnal/xato-xabari bilan solishtirilgani ko'rinadi — «aytdi, qildim» yetarli emas;
3) eslatmada 2–3 aniq adashuv-holati bor (masalan: rasm-fayl haqida so'ralganda, jurnalsiz taxmin qilganda).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- So'rov loyqa bo'lsa — darsdagi solishtiruvni eslating: dalilsiz so'rovga yordamchi javob berolmaydi; to'g'ri so'rovni yozib bermang.
- Tekshirishsiz qabul ko'rinsa — bosh qoidani eslating: taklif — taxmin, tugmani o'quvchi bosadi.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: yordamchi tez, tekshiruvchi esa — o'zi.
```

## `ru` · Matn

```
Пройдите четыре шага с помощником на своём проекте — письменно выполните три задания:

1. Испытайте: вызовите в проекте одну ошибку (или возьмите существующую) и попросите помощника (Antigravity или другой AI) о помощи ТОЧНЫМ запросом. Запишите запрос полностью — шаблон урока: файл + строка + ожидалось/пришло.
2. Проверьте: запишите, как сравнили предложение помощника с журналом или сообщением об ошибке — совпало ли, приняли ли после этого.
3. Запишите: в каких случаях помощник может ошибаться — памятка себе с 2–3 примерами.
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по AI-помощнику ученика 13 лет. 3 задания: точный запрос, проверка, памятка.

Критерии приёма:
1) запрос по шаблону урока: имя файла + строка (или точное место) + ожидаемое и пришедшее значение — размытый запрос «не работает, что делать?» не проходит;
2) в описании проверки видно сравнение предложения с журналом/сообщением об ошибке — «сказал — сделал» недостаточно;
3) в памятке 2–3 конкретных случая ошибок (например: вопрос про файл-картинку, догадка без журнала).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если запрос размыт — напомните сравнение из урока: без улик помощник ответить не может; верный запрос не выписывайте.
- Если принято без проверки — напомните главное правило: предложение — догадка, кнопку нажимает ученик.
- Если всё в порядке — похвалите одной фразой: помощник быстр, а проверяющий — он сам.
```
