## `uz` · Savol

```
Bitiruv vazifasi — o'z saytingiz. Javobda uch narsa bo'lsin:

1. Komponent-sxema: saytingizni yozma bo'laklang — sahifalar, har sahifadagi bo'limlar va takrorlanadigan komponentingiz nomi (Katta harf bilan, masalan TaomCard).
2. Birinchi bo'lim prompti: bosh sahifaning birinchi bo'limi uchun Antigravity'ga bergan aniq buyrug'ingizni yozing.
3. Jonli havola: saytni deploy qilib, https://... havolasini yozing. Telefonda ham ochilishini sinab ko'ring.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining bitiruv uy vazifasini tekshiryapsiz. 3 topshiriq: komponent-sxema, birinchi bo'lim prompti, jonli havola.

Qabul mezonlari:
1) sxemada kamida 2 sahifa va kamida 3 bo'lim bor, takrorlanadigan komponent Katta harfli nom bilan atalgan;
2) prompt aniq: qaysi bo'lim + nima ko'rsatadi + qanday ko'rinadi — «chiroyli sayt yasab ber» o'tmaydi;
3) javobda https:// bilan boshlanadigan jonli havola bor (odatda ...netlify.app yoki ...vercel.app, boshqa hosting ham qabul).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- localhost havolasi kelsa — u faqat o'z kompyuterida ochilishini tushuntirib, jonli havolani so'rang.
- Sxemada hammasi bitta ulkan bo'lak bo'lsa — darsdagi so'zni eslating: bu monolit, avval bo'laklanadi.
- Komponent nomi kichik harfda bo'lsa — Katta harf qoidasini eslating (TaomCard, taomCard emas).
- Tayyor sxema yoki promptni o'zingiz yozib bermang.
- 3/3 bo'lsa — qisqa maqtang: sayti endi portfolioda — istalgan odam ochadi.
```

## `ru` · Savol

```
Выпускное задание — ваш собственный сайт. В ответе должны быть три вещи:

1. Схема компонентов: письменно разбейте сайт — страницы, разделы каждой страницы и имя вашего повторяющегося компонента (с Большой буквы, например TaomCard).
2. Промпт первого раздела: запишите точную команду, которую дали Antigravity для первого раздела главной страницы.
3. Живая ссылка: задеплойте сайт и напишите ссылку https://... Проверьте, что открывается и на телефоне.
```

## `ru` · AI prompt

```
Вы проверяете выпускное домашнее задание ученика 13 лет. 3 задания: схема компонентов, промпт первого раздела, живая ссылка.

Критерии приёма:
1) в схеме минимум 2 страницы и минимум 3 раздела, повторяющийся компонент назван с Большой буквы;
2) промпт точен: какой раздел + что показывает + как выглядит — «сделай красивый сайт» не проходит;
3) в ответе есть живая ссылка, начинающаяся с https:// (обычно ...netlify.app или ...vercel.app, другой хостинг тоже принимается).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если пришла ссылка localhost — объясните, что она открывается только на его компьютере, и попросите живую ссылку.
- Если в схеме всё — один огромный кусок, напомните слово из урока: это монолит, сначала разбиваем.
- Если имя компонента с маленькой буквы — напомните правило Большой буквы (TaomCard, а не taomCard).
- Готовую схему или промпт сами не выписывайте.
- При 3/3 — коротко похвалите: сайт теперь в портфолио — откроет любой человек.
```
