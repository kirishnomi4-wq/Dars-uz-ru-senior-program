## `uz` · Savol

```
Darsda AvtoIjarani qurdingiz — endi O'Z ilovangizni boshlaysiz (mashina emas!). Yozma javob bering:

1. G'oya: bir gap — qanday ilova va u kimga kerak.
2. Reja: sahifalar ro'yxati (kamida 3 ta) va har sahifada qanday ma'lumot ko'rinadi.
3. Birinchi prompt: Antigravity'ga bergan (yoki beradigan) BIRINCHI buyrug'ingizni to'liq yozing — darsdagi qolip bilan: Nima + Qanday + Qayerda.
4. Natija: qurishni boshlagan bo'lsangiz — nima ishladi, 1–2 gap. Hali boshlamagan bo'lsangiz — birinchi qadamda nimani tekshirishingizni yozing.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining loyiha-kuni uy vazifasini tekshiryapsiz. 4 topshiriq: g'oya, reja, birinchi prompt, natija.

Qabul mezonlari:
1) g'oya bir gapda va o'ziniki (AvtoIjara/mashina emas), kimga kerakligi aytilgan;
2) rejada kamida 3 sahifa bor va har sahifada qanday ma'lumot ko'rinishi yozilgan;
3) prompt darsdagi qolipga mos: NIMA qurilsin + QANDAY ko'rinsin/ishlasin + QAYERDA tursin — «sayt yasab ber» kabi loyqa buyruq o'tmaydi;
4) natija-bandida aniq gap bor (nima ishladi yoki nimani tekshiradi).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Prompt loyqa bo'lsa — qaysi qismi yetishmasligini ayting (Nima? Qanday? Qayerda?), to'g'ri promptni o'zingiz yozib bermang.
- Reja sahifalari bir-birini takrorlasa — har sahifaning alohida ishi bo'lishini eslating.
- G'oya tanloviga baho bermang — g'oya o'quvchiniki.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: endi u loyiha boshlig'i, AI esa quruvchisi.
```

## `ru` · Savol

```
На уроке вы построили АвтоАренду — теперь начинаете СВОЁ приложение (не про машины!). Ответьте письменно:

1. Идея: одна фраза — какое приложение и кому оно нужно.
2. План: список страниц (минимум 3) и какие данные видны на каждой.
3. Первый промпт: полностью запишите ПЕРВУЮ команду, которую дали (или дадите) Antigravity — по шаблону урока: Что + Как + Где.
4. Результат: если уже начали строить — что заработало, 1–2 фразы. Если ещё нет — что проверите на первом шаге.
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание дня проекта ученика 13 лет. 4 задания: идея, план, первый промпт, результат.

Критерии приёма:
1) идея в одной фразе и собственная (не АвтоАренда/машины), сказано, кому нужно;
2) в плане минимум 3 страницы, и для каждой записано, какие данные видны;
3) промпт по шаблону урока: ЧТО построить + КАК выглядеть/работать + ГДЕ стоять — размытая команда «сделай сайт» не проходит;
4) в пункте результата есть конкретная фраза (что заработало или что проверит).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если промпт размыт — назовите, какой части не хватает (Что? Как? Где?), но правильный промпт сами не выписывайте.
- Если страницы плана повторяют друг друга — напомните: у каждой страницы своё отдельное дело.
- Выбор идеи не оценивайте — идея принадлежит ученику.
- Если всё в порядке — похвалите одной фразой: теперь он руководитель проекта, а AI — строитель.
```
