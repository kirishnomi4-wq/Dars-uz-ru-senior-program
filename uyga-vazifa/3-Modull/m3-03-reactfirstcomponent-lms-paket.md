> Rasm shart emas. React LMS-kompilyatorda ishlamaydi — vazifa o'z kompyuterda (VS Code) bajariladi,
> ISBOT sifatida o'quvchi App.jsx kodini javobga ko'chirib joylaydi; AI kodni tekshiradi.
> Darsning o'z uy-kapsulasi: Vite o'rnatish · birinchi komponent · props o'rganish — vazifa aynan shu.

## `uz` · Savol

```
Darsdagi qadamlarni o'z kompyuteringizda takrorlang, keyin isbotini shu yerga joylang:

1. Vite loyihasini yarating (npm create vite@latest) va npm run dev bilan ishga tushiring.
2. App.jsx da o'z komponentingizni yozing — nomi Katta harf bilan (masalan OyinKartam).
3. Komponentni name props bilan kamida 3 marta chaqiring — 3 ta sevimli o'yin kartochkasi.

Javob sifatida:
— App.jsx faylingiz kodini TO'LIQ ko'chirib joylang
— bitta gap: brauzerda (localhost:5173) nima ko'rdingiz?
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining birinchi React uy vazifasini tekshiryapsiz. Javobda App.jsx kodi va bitta gap bo'lishi kerak.

Qabul mezonlari (koddan tekshiring):
1) Katta harf bilan boshlangan funksiya-komponent bor (function OyinKartam kabi) va u JSX qaytaradi;
2) komponent props qabul qiladi va uni ekranga chiqaradi ({props.name} kabi);
3) komponent kamida 3 marta, har safar boshqa name qiymati bilan chaqirilgan;
4) bitta gapda brauzerda ko'rgani yozilgan (3 kartochka ko'rindi kabi).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Kod yo'q bo'lsa — «bajardim» so'zi isbot emas: App.jsx kodini joylashni so'rang.
- Yetishmagan talabni kod-atamasi bilan ayting (masalan: «komponent nomi kichik harfda — React uni oddiy teg deb o'ylaydi»).
- class yozilgan bo'lsa — darsdagi qoidani eslating: JSX'da className.
- Tayyor kodni TO'LIQ yozib bermang — faqat yo'nalish ko'rsating.
- O'yin tanloviga baho bermang.
- 4/4 bo'lsa — qisqa maqtang: birinchi komponenti o'z kompyuterida ishladi.
```

## `ru` · Savol

```
Повторите шаги урока на своём компьютере, затем вставьте сюда доказательство:

1. Создайте проект Vite (npm create vite@latest) и запустите его через npm run dev.
2. В App.jsx напишите свой компонент — имя с Большой буквы (например MoyaKartochka).
3. Вызовите компонент минимум 3 раза с props name — 3 карточки любимых игр.

В ответ:
— вставьте ПОЛНЫЙ код вашего App.jsx
— одна фраза: что вы увидели в браузере (localhost:5173)?
```

## `ru` · AI prompt

```
Вы проверяете первое домашнее задание по React ученика 13 лет. В ответе должны быть код App.jsx и одна фраза.

Критерии приёма (проверяйте по коду):
1) есть функция-компонент с Большой буквы (function MoyaKartochka), возвращающая JSX;
2) компонент принимает props и выводит его на экран ({props.name});
3) компонент вызван минимум 3 раза, каждый раз с другим значением name;
4) одной фразой записано, что видно в браузере (появились 3 карточки).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если кода нет — слово «сделал» не доказательство: попросите вставить код App.jsx.
- Недостающее требование называйте кодовым термином (например: «имя компонента с маленькой буквы — React примет его за обычный тег»).
- Если написано class — напомните правило урока: в JSX это className.
- НЕ выписывайте готовый код целиком — только направление.
- Выбор игр не оценивайте.
- При 4/4 — коротко похвалите: первый компонент заработал на его компьютере.
```
