# 🏠 LMS-PAKET — ReactIntroLesson (M3-01) · savol-turi: Text

> Rasm shart emas (yozma kuzatuv — dars tushuncha-darsi, kod hali yozilmaydi).
> Darsning o'z uy-kapsulasi: komponentlarni topish · bo'laklash · kuzatuv — vazifa aynan shu.

---

## `uz` · Matn

```
Detektiv bo'ling — ilovalarning ichidan komponentlarni toping. Uchala topshiriqqa yozma javob bering:

1. Komponentlarni topish: Instagram yoki YouTube'ni oching va takrorlanadigan 5 ta bo'lakni toping — nomlarini yozing (masalan: video-kartochka).
2. Bo'laklash: sevimli saytingiz bosh sahifasini komponentlarga bo'lib, ro'yxat qilib yozing — tepadan pastgacha, kamida 4 bo'lak.
3. Kuzatuv: 3 ta ilovada like yoki tugma bosing va yozing: sahifa to'liq yangilandimi yoki faqat bir joyi o'zgardimi?
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining «React nima?» darsi bo'yicha yozma javoblarini tekshiryapsiz. 3 topshiriq: komponentlarni topish, bo'laklash, kuzatuv.

Qabul mezonlari:
1) kamida 5 ta takrorlanadigan bo'lak nomlangan va ular chindan takrorlanadigan narsalar (video-kartochka, izoh, tugma kabi) — «ekran», «telefon» kabi javoblar bo'lak emas;
2) bitta saytning bosh sahifasi kamida 4 bo'lakka ajratilgan va tartibi mantiqiy (tepadagi menyu, o'rtadagi ro'yxat, pastdagi qism kabi);
3) 3 ilova bo'yicha kuzatuv yozilgan va xulosada «faqat bir joyi o'zgardi» ma'nosi bor — bu Virtual DOM darsdagi 3 qadamiga mos.

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Qaysi topshiriq chala ekanini aniq ayting.
- Bo'lak nomi juda umumiy bo'lsa («narsa», «joy») — aniqroq nom so'rang, javobni o'zingiz yozib bermang.
- Ilova tanloviga baho bermang.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: endi ilovalarni React ko'zi bilan ko'radi.
```

## `ru` · Matn

```
Побудьте детективом — найдите компоненты внутри приложений. Письменно выполните три задания:

1. Охота на компоненты: откройте Instagram или YouTube и найдите 5 повторяющихся частей — запишите их названия (например: карточка видео).
2. Разбивка: разбейте главную страницу любимого сайта на компоненты и запишите списком — сверху вниз, минимум 4 части.
3. Наблюдение: нажмите лайк или кнопку в 3 приложениях и запишите: страница обновилась целиком или изменилось только одно место?
```

## `ru` · AI prompt

```
Вы проверяете письменные ответы ученика 13 лет по уроку «Что такое React?». 3 задания: охота на компоненты, разбивка, наблюдение.

Критерии приёма:
1) названо минимум 5 повторяющихся частей, и это действительно повторяющиеся вещи (карточка видео, комментарий, кнопка) — «экран», «телефон» частями не считаются;
2) главная страница одного сайта разбита минимум на 4 части, порядок логичен (меню сверху, список в середине, нижняя часть);
3) наблюдение записано по 3 приложениям, и в выводе есть смысл «изменилось только одно место» — это соответствует 3 шагам Virtual DOM из урока.

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Точно называйте, какое задание недоделано.
- Если название части слишком общее («вещь», «место») — попросите точнее, но сами ответ не выписывайте.
- Выбор приложений не оценивайте.
- Если всё в порядке — похвалите одной фразой: теперь ученик видит приложения глазами React.
```
