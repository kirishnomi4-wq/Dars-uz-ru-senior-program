Наверху каждого сайта есть меню — теперь сделайте своё. В index.html переименуйте пункты меню под свой сайт, а в style.css наведите порядок с помощью Flexbox.

Выполнены все три требования — задание готово. Дополнительно: откройте готовое меню в браузере через F12 → Styles и поменяйте значения.
