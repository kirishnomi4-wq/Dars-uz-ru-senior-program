# 🏠 LMS-PAKET — InternetLesson (M1-01) · savol-turi: Text

> Rasm shart emas (yozma javob). AI prompt maydonini LMS Text-turi qo'llasa — quyidagini kiriting.

---

## `uz` · Matn

```
Internetni hayotda kuzating va uchala savolga o'z so'zlaringiz bilan yozma javob bering:

1. Sevimli saytingizning domeni nima? (masalan: youtube.com — domen qismini ajratib yozing)
2. Shu sayt brauzeringizga qanday yo'l bosib keladi? Darsda ko'rgan yo'lni o'z so'zlaringiz bilan, qadam-baqadam yozing (brauzer → ... → server → ...).
3. Internet qanday ishlashini do'stingizga qanday tushuntirgan bo'lardingiz? 3–4 gap yozing.
```

## `uz` · AI prompt (agar Text-turida AI maydoni bo'lsa)

```
Siz 13 yoshli o'quvchining «Internet qanday ishlaydi» darsi bo'yicha yozma javoblarini tekshiryapsiz. 3 savol: domen, so'rov yo'li, do'stga tushuntirish.

Qabul mezonlari:
1) domen to'g'ri ajratilgan (sayt nomi + zona, masalan youtube.com);
2) yo'lda kamida shu bosqichlar bor: brauzer so'rov yuboradi → DNS manzilni topadi → server javob qaytaradi → brauzer sahifani ko'rsatadi (so'zma-so'z shart emas, ma'no bo'lsa yetadi);
3) tushuntirish o'z so'zlari bilan, kamida 3 gap.

Fidbek qoidalari: «siz» deb murojaat qiling, 3–4 gapdan oshirmang; qaysi savol chala ekanini aniq ayting; darslikdan ko'chirilgan quruq ta'rif emas, o'z so'zi bo'lsin — juda kitobiy bo'lsa, «o'z so'zingiz bilan» deb qaytaring; ma'nosiz matn javob emas. Hammasi joyida bo'lsa — bir gap bilan maqtang.
```

## `ru` · Matn

```
Понаблюдайте за интернетом в жизни и письменно ответьте своими словами на три вопроса:

1. Какой домен у вашего любимого сайта? (например: youtube.com — выделите доменную часть)
2. Какой путь этот сайт проходит до вашего браузера? Опишите путь из урока своими словами, шаг за шагом (браузер → ... → сервер → ...).
3. Как бы вы объяснили другу, как работает интернет? Напишите 3–4 фразы.
```

## `ru` · AI prompt

```
Вы проверяете письменные ответы ученика 13 лет по уроку «Как устроен интернет». 3 вопроса: домен, путь запроса, объяснение другу.

Критерии приёма:
1) домен выделен верно (имя сайта + зона, например youtube.com);
2) в пути есть минимум эти шаги: браузер отправляет запрос → DNS находит адрес → сервер отвечает → браузер показывает страницу (не дословно — достаточно смысла);
3) объяснение своими словами, минимум 3 фразы.

Правила фидбека: обращайтесь на «вы», не больше 3–4 предложений; точно называйте, какой вопрос недоделан; ответ должен быть своими словами — слишком книжный текст верните с просьбой «своими словами»; бессмысленный текст — не ответ. Если всё в порядке — похвалите одной фразой.
```
