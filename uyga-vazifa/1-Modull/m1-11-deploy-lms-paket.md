## `uz` · Matn

```
Saytingiz endi internetda! Uyda uni oxirigacha tugating:

1. Saytni uyda tugating — kontent va bezakni yakunlang
2. Jonli havolani tekshiring — telefonda ham ochilishini sinang
3. Havolani shu yerga yozib yuboring

Javob sifatida:
— jonli sayt havolangiz (https://...netlify.app ko'rinishida)
— bitta gap: saytingizni birinchi bo'lib kimga ko'rsatdingiz va u nima dedi?
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining deploy uy vazifasini tekshiryapsiz. Vazifa: saytni uyda tugatib, jonli havolani topshirish.

Qabul mezonlari:
1) javobda https:// bilan boshlanadigan jonli sayt havolasi bor (odatda ...netlify.app, boshqa hosting ham qabul);
2) saytni kimgadir ko'rsatgani haqida kamida bitta gap bor.

Fidbek qoidalari: «siz» deb murojaat qiling, 2–3 gapdan oshirmang; havola formati buzuq bo'lsa to'g'ri ko'rinishni ko'rsating; localhost havolasi kelsa — bu faqat o'z kompyuterida ochilishini tushuntirib, jonli havolani so'rang. Hammasi joyida bo'lsa — qisqa maqtang: birinchi modul sayti endi butun internetda ochiladi.
```

## `ru` · Matn

```
Ваш сайт теперь в интернете! Доделайте его дома до конца:

1. Доделайте сайт дома — контент и оформление
2. Проверьте живую ссылку — пусть открывается и на телефоне
3. Отправьте ссылку сюда

В ответ напишите:
— живую ссылку на сайт (в виде https://...netlify.app)
— одну фразу: кому вы первому показали свой сайт и что он сказал?
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по деплою ученика 13 лет. Задание: доделать сайт дома и сдать живую ссылку.

Критерии приёма:
1) в ответе есть живая ссылка, начинающаяся с https:// (обычно ...netlify.app, другой хостинг тоже принимается);
2) есть минимум одна фраза о том, кому ученик показал сайт.

Правила фидбека: обращайтесь на «вы», не больше 2–3 предложений; если формат ссылки сломан — покажите правильный вид; если пришла ссылка localhost — объясните, что она открывается только на его компьютере, и попросите живую ссылку. Если всё в порядке — коротко похвалите: сайт первого модуля теперь открывается во всём интернете.
```
