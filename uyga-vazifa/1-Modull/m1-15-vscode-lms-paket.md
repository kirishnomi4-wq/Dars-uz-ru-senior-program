## `uz` · Sarlavha

```
Cardingizni VS Code'da boyiting
```

## `uz` · Text

```
Darsda yasagan card'ingizni uy kompyuteringizda VS Code'da ochib boyiting. Har o'zgarishdan keyin Ctrl+S bosing — brauzer o'zi yangilanadi (Live Server).

Vazifa:
1. Hobbi ro'yxati — card ichiga <ul>/<li> bilan 3 ta hobbingiz
2. Havola — Telegram yoki sevimli saytingizga <a href="...">
3. Rang tajribasi — card fonini boshqa rangga o'zgartiring
4. Sahifa nomi — <title> ichiga ismingizni yozing (brauzer tab'ida ko'rinadi)

Tayyor bo'lgach: brauzerda ochilgan card'ning SKRINSHOTINI shu yerga yuklang (skrinshotda brauzer tab'i ham ko'rinsin — title tekshiriladi). Card faylini keyingi darsga ham olib keling — mentor jonli ko'radi.
```

## `ru` · Sarlavha

```
Обогатите свою карточку в VS Code
```

## `ru` · Text

```
Карточку, сделанную на уроке, откройте дома в VS Code и обогатите. После каждого изменения нажимайте Ctrl+S — браузер обновится сам (Live Server).

Задание:
1. Список хобби — 3 ваших хобби внутри карточки через <ul>/<li>
2. Ссылка — <a href="..."> на Telegram или любимый сайт
3. Эксперимент с цветом — поменяйте фон карточки на другой цвет
4. Имя страницы — напишите своё имя в <title> (видно на вкладке браузера)

Когда будет готово: загрузите сюда СКРИНШОТ карточки, открытой в браузере (пусть на скриншоте видна и вкладка браузера — по ней проверяется title). Файл карточки принесите и на следующий урок — ментор посмотрит вживую.
```
