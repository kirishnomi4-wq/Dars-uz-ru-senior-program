```
HTML darslarida yozgan «men haqimda» sahifangizni endi CSS bilan bezang: index.html ichiga o'z sahifangizni yozing, style.css da esa bezak bering.

Talablar (style.css da):
1. body — background-color (sahifa foni)
2. h1 — color (sarlavha rangi)
3. body — font-family (shrift)
4. h1 — font-size (o'lcham)
5. body — padding (sahifa chetlariga havo)
6. p — margin (paragraflar orasi)

Oltala talab bajarilsa, vazifa tayyor. Ranglarni o'zingizga yoqqanini tanlang — bu SIZNING sahifangiz.
```

Qo'shimcha tekshiruv: HTML qismida o'quvchining O'Z matni bo'lsin (h1 + kamida 1-2 p) — zagotovkadagi «Bu yerga o'zingiz haqingizda gap yozing» matni o'zgarmagan bo'lsa, o'z matnini yozishga qaytaring.

## `ru` · Savol

```
Страницу «обо мне» из уроков HTML теперь украсьте с помощью CSS: в index.html напишите свою страницу, а в style.css задайте оформление.

Требования (в style.css):
1. body — background-color (фон страницы)
2. h1 — color (цвет заголовка)
3. body — font-family (шрифт)
4. h1 — font-size (размер)
5. body — padding (воздух у краёв страницы)
6. p — margin (расстояние между абзацами)

Выполнены все шесть требований — задание готово. Цвета выбирайте на свой вкус — это ВАША страница.
```

## `ru` · AI prompt

```
Вы проверяете первое домашнее задание по CSS ученика 13 лет. Задание: украсить свою HTML-страницу «обо мне» с помощью CSS (index.html + style.css).

Критерии приёма (принято при 6/6):
1) у body задан background-color;
2) у h1 задан color;
3) у body задан font-family;
4) у h1 задан font-size;
5) у body задан padding;
6) у p задан margin.

Дополнительная проверка: в HTML должен быть СОБСТВЕННЫЙ текст ученика (h1 + минимум 1–2 p) — если текст заготовки «Напишите здесь фразу о себе» не изменён, верните к написанию своего текста.

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Недостающее свойство называйте вместе с селектором (например: «у body ещё нет padding»).
- НЕ выписывайте готовое решение целиком — только направление.
- Выбор цвета не оценивайте — никаких «некрасивый цвет»: цвет — вкус ученика.
- Сломанный синтаксис CSS (незакрытая скобка, нет точки с запятой): «Код не заработал: ...» и покажите место.
- При 6/6 — коротко похвалите: у страницы теперь есть своё лицо.
```
