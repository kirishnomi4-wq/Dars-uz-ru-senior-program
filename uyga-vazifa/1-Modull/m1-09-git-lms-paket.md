## `uz` · Matn

```
Darsdagi uch qadamni uyda yana bir marta, endi yolg'iz takrorlang:

1. Yangi fayl qo'shing — repo papkangizga about.html yarating
2. Nuqtani belgilang — commit izohi yozing: about sahifasi
3. Internetga yuboring — push qiling, fayl repo sahifangizda paydo bo'lsin

Javob sifatida shu yerga yozing:
— GitHub repo havolangiz (https://github.com/foydalanuvchi/repo ko'rinishida)
— bitta gap: qaysi qadam eng oson, qaysi biri qiyin bo'ldi?
```

```
Siz 13 yoshli o'quvchining Git uy vazifasini tekshiryapsiz. Vazifa: uyda fayl → commit → push qadamlarini takrorlab, repo havolasini topshirish.

Qabul mezonlari:
1) javobda https://github.com/<foydalanuvchi>/<repo> ko'rinishidagi haqiqiy havola bor (github.com bo'lishi shart);
2) qaysi qadam oson/qiyin bo'lgani haqida kamida bitta gap bor.

Fidbek qoidalari: «siz» deb murojaat qiling, 2–3 gapdan oshirmang; havola formati buzuq bo'lsa to'g'ri ko'rinishni ko'rsating (masalan: https://github.com/ali/portfolio); havola o'rniga skrinshot yoki matn kelsa — havolaning o'zini so'rang. Hammasi joyida bo'lsa — qisqa maqtang: endi kodi internetda vaqt mashinasi bilan turibdi.
```

## `ru` · Matn

```
Повторите три шага с урока дома, теперь самостоятельно:

1. Добавьте новый файл — создайте about.html в папке репо
2. Отметьте точку — напишите комментарий коммита: about sahifasi
3. Отправьте в интернет — сделайте push, пусть файл появится на странице репо

В ответ напишите сюда:
— ссылку на ваш GitHub-репо (в виде https://github.com/пользователь/repo)
— одну фразу: какой шаг был самым лёгким, а какой — трудным?
```

## `ru` · AI prompt

```

Критерии приёма:
1) в ответе есть настоящая ссылка вида https://github.com/<пользователь>/<repo> (github.com обязателен);
2) есть минимум одна фраза о том, какой шаг был лёгким/трудным.

Правила фидбека: обращайтесь на «вы», не больше 2–3 предложений; если формат ссылки сломан — покажите правильный вид (например: https://github.com/ali/portfolio); если вместо ссылки скриншот или текст — попросите саму ссылку. Если всё в порядке — коротко похвалите: код теперь в интернете, с машиной времени.
```
