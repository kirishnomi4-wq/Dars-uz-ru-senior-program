# 🏠 LMS-PAKET — ApiPostmanLesson (M4-09) · savol-turi: Text

> Rasm shart emas (yozma hisobot — darsning o'z kapsulasi: Postman o'rnatish · ochiq API · 4 method).

---

## `uz` · Matn

```
Postachi bo'ling — uchala topshiriqqa yozma javob bering:

1. Postman'ni o'rnating (postman.com, bepul; Thunder Client ham bo'ladi) — qaysi birini o'rnatganingizni yozing.
2. Ochiq API'ga GET so'rov yuboring va yozing: qaysi manzilga yubordingiz, qaysi status kodi keldi, JSON javobdan bitta maydon nomi.
3. To'rttala method'ni CRUD amali bilan juftlab yozing: GET, POST, PUT, DELETE.

Javob oxirida bitta gap: manzilni ataylab xato yozsangiz qaysi kod keladi va u nimani anglatadi?
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining API/Postman uy vazifasini tekshiryapsiz. 3 topshiriq + bitta gap.

Qabul mezonlari:
1) qaysi asbob o'rnatilgani yozilgan (Postman yoki Thunder Client);
2) haqiqiy so'rov hisoboti bor: manzil + status kodi (200) + JSON'dan bitta maydon nomi;
3) to'rttala juftlik to'g'ri: GET → Read (o'qish), POST → Create (yaratish), PUT → Update (yangilash), DELETE → Delete (o'chirish);
4) bitta gapda 404 va ma'nosi («bunday manzil topilmadi») yozilgan.

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- So'rov-hisoboti umumiy bo'lsa («yubordim, keldi») — manzil va maydon nomini so'rang: shtampsiz konvert hisob emas.
- Juftlik xato bo'lsa — konvert-o'xshatishni eslating: method konvertdagi niyat; to'g'ri javobni aytmang.
- Hammasi joyida bo'lsa — bir gap bilan maqtang: endi u serverlar bilan konvert tilida gaplasha oladi.
```

## `ru` · Matn

```
Побудьте почтальоном — письменно выполните три задания:

1. Установите Postman (postman.com, бесплатно; Thunder Client тоже подходит) — напишите, что установили.
2. Отправьте GET-запрос на открытый API и запишите: на какой адрес отправили, какой статус пришёл, имя одного поля из JSON-ответа.
3. Запишите все четыре метода парой с действием CRUD: GET, POST, PUT, DELETE.

В конце ответа одна фраза: какой код придёт, если нарочно написать адрес с ошибкой, и что он означает?
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по API/Postman ученика 13 лет. 3 задания + одна фраза.

Критерии приёма:
1) записано, какой инструмент установлен (Postman или Thunder Client);
2) есть отчёт о настоящем запросе: адрес + статус (200) + имя одного поля из JSON;
3) все четыре пары верны: GET → Read (чтение), POST → Create (создание), PUT → Update (обновление), DELETE → Delete (удаление);
4) одной фразой записаны 404 и смысл («такой адрес не найден»).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если отчёт о запросе общий («отправил, пришло») — попросите адрес и имя поля: конверт без штампа не считается.
- Если пара неверна — напомните сравнение с конвертом: method — намерение на конверте; правильный ответ не говорите.
- Если всё в порядке — похвалите одной фразой: теперь он говорит с серверами на языке конвертов.
```
