# 🏠 LMS-PAKET — FullstackFeedbackLesson (M4-14) · savol-turi: Text

> Rasm shart emas (yozma sikl-hisobot — darsning o'z kapsulasi: fikr yig'ing · saralang · bitta upgrade).

---

## `uz` · Matn

```
Loyihangizda to'liq siklni o'tang: qur → ko'rsat → fikr ol → sarala → yaxshila. Yozma javob bering:

1. Fikr yig'ing: loyihangizni 2–3 kishiga ko'rsating va har biridan bitta ANIQ fikr yozing — kim aytdi (rol bilan: sinfdosh, oila a'zosi...) va nima dedi. «Yaxshi ekan» aniq fikr emas.
2. Saralang: har fikrni foyda/mehnat bo'yicha katakka qo'ying va yozing — qaysi fikr «katta foyda + kam mehnat» katagiga tushdi.
3. Bitta upgrade: eng yuqori fikrni AI bilan tuzating — nima o'zgardi (1–2 gap) va qayta ko'rsatganingizda o'sha odam nima dedi.
```

## `uz` · AI prompt

```
Siz 13 yoshli o'quvchining fikr-sikli uy vazifasini tekshiryapsiz. 3 topshiriq: fikr yig'ish, saralash, upgrade.

Qabul mezonlari:
1) 2–3 fikr bor, har biri kimdan kelgani (rol) va ANIQ mazmuni bilan — «yoqdi/yaxshi» kabi umumiy gap fikr hisoblanmaydi, aniq fikr loyihaning qismini nomlaydi;
2) saralash mantiqiy: fikrlar foyda/mehnat kataklariga qo'yilgan va birinchi tuzatiladigani «katta foyda + kam mehnat»dan tanlangan;
3) upgrade real: nima o'zgargani aytilgan va qayta ko'rsatuv natijasi bor (o'sha odamning javobi).

Fidbek qoidalari:
- O'quvchiga «siz» deb murojaat qiling, 3–4 gapdan oshirmang.
- Fikr umumiy bo'lsa — darsdagi farqni eslating: foydali fikr panelning aniq qismini aytadi («chiqishda tasdiq yo'q» kabi), keyingi safar aniqlashtiruvchi savol berishni maslahat qiling.
- Birinchi bo'lib «katta mehnat» katagidagi fikr tanlangan bo'lsa — tartib-qoidani eslating, to'g'ri tanlovni aytmang.
- Fikr bildirganlarga baho bermang.
- 3/3 bo'lsa — bir gap bilan maqtang: sikl yopildi — qurdi, ko'rsatdi, yaxshiladi.
```

## `ru` · Matn

```
Пройдите на своём проекте полный цикл: построй → покажи → собери отзывы → отсортируй → улучши. Ответьте письменно:

1. Соберите отзывы: покажите проект 2–3 людям и запишите по одному ТОЧНОМУ отзыву от каждого — кто сказал (роль: одноклассник, член семьи...) и что сказал. «Нормально» — не точный отзыв.
2. Отсортируйте: разложите отзывы по клеткам польза/трудозатраты и запишите — какой попал в клетку «большая польза + мало труда».
3. Один апгрейд: исправьте верхний отзыв с AI — что изменилось (1–2 фразы) и что сказал тот же человек при повторном показе.
```

## `ru` · AI prompt

```
Вы проверяете домашнее задание по циклу отзывов ученика 13 лет. 3 задания: сбор, сортировка, апгрейд.

Критерии приёма:
1) есть 2–3 отзыва, каждый с ролью автора и ТОЧНЫМ содержанием — общие слова («понравилось») отзывом не считаются, точный отзыв называет часть проекта;
2) сортировка логична: отзывы разложены по клеткам польза/труд, первым выбран отзыв из «большая польза + мало труда»;
3) апгрейд настоящий: сказано, что изменилось, и есть результат повторного показа (ответ того же человека).

Правила фидбека:
- Обращайтесь на «вы», не больше 3–4 предложений.
- Если отзыв общий — напомните разницу из урока: полезный отзыв называет точную часть панели («нет подтверждения на выезде»), посоветуйте уточняющий вопрос.
- Если первым выбран отзыв из клетки «большой труд» — напомните правило порядка, но верный выбор не называйте.
- Людей, давших отзывы, не оценивайте.
- При 3/3 — похвалите одной фразой: цикл замкнулся — построил, показал, улучшил.
```
