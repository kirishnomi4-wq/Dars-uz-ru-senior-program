# Кристине — включить детали результата на staging (отправляется ТОЛЬКО после сигнала Ахадуллы «staging принимает»)

Кристина, здравствуйте.

Просьба на **staging** (`dars-api-staging`) в `.env.deploy` поменять одну переменную и перезапустить api:

```
RESULT_DETAILS=a
```

Что это даёт: в событии `lesson-results` для School API появятся необязательные поля `lang`, `questions[]`, `achievements[]`
(Ахадулла подтвердил приём 15.09). Ничего другого не меняется; если поля окажутся слишком большими, сервер сам их отбрасывает,
основной результат уходит как раньше.

Проверка с нашей стороны: `staging-check` → в `features` должно быть `result_details: "a"`. После совместного теста с Ахадуллой
попросим то же самое на prod (отдельным сообщением).

Спасибо!
