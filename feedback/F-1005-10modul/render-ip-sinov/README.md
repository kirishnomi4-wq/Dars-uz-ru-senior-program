# Render IP sinovi (10-Modul 8-dars, QAROR 10M-58 · 8-q3)

Maqsad: Render'da o'yinchining haqiqiy IP manzili qaysi sarlavhada kelishini o'z ko'zimiz bilan ko'rish. Natijaga qarab 8-dars Yordam namunasidagi bitta qator muzlatiladi.

## Qo'yish (≈10 daqiqa)
1. GitHub'da yangi bo'sh repo (masalan `ip-sinov`) → shu papkadagi `server.js` va `package.json` ni yuklang (Add file → Upload files).
2. Render → New → Web Service → shu repo. Build Command: `npm install` · Start Command: `npm start` · Instance: Free.
3. Deploy tugagach berilgan `https://….onrender.com` manzilni oching.

## Tekshirish
1. Noutbukda manzilni oching. Yangi tabda https://ifconfig.me ni oching va u ko'rsatgan IP ni yozib oling.
2. Telefonda Wi-Fi ni o'chirib (mobil internet) xuddi shuni qiling.
3. Ikkala JSON ni chatga tashlang. Qaysi qator `ifconfig.me` dagi IP bilan bir xil ekanini men solishtiraman.

Sinovdan keyin Render'dagi servisni o'chirib qo'ying (Settings → Delete Web Service).
