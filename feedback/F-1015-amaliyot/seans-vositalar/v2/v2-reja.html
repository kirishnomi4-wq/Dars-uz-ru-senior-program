CSS Praktika v2: Demo Day sayti shu yerda boshlanadi

Sizning g'oyangiz: CSS Praktikada Demo Day saytining bosh sahifasi quriladi (HTML'ni Gemini tez yozadi, urg'u CSS'ga), Netlify darsida esa qolgan sahifalar ~40 daqiqada tugatilib, internetga chiqariladi. Qolip o'sha: 9 ekran, ustoz bilan, isbotsiz.

Koddan tekshirilgan faktlar

Takror borHTML Praktika A4 da portfolio Gemini bilan bezatiladi — CSS Praktika uni yana bezaydi.
Demo Day ipi borg'oya PM darsida tanlanadi, VS Code darsida tasdiqlanadi, Deploy va Demo Day darslari uni o'qiydi.
Deploy og'irsaytni noldan quradi: muammo → 4 sahifa → mazmun → uslub → AI kod → yaxshilash → Netlify.
Git darsi xalaqit bermaydialohida mashq repo'si (index.html + about.html); Netlify'ga GitHub bilan kiriladi.
