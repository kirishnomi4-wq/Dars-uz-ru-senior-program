## 0 · Kirish
- Eyebrow: Kirish
- Sarlavha: Oltita g'oyani *qayerdan topasiz?*
- Mentor: Bu modulda bitiruvgacha quriladigan mahsulot tanlanadi: o'zingizga yaqin javobni belgilang.
- Maket (chapda, uch obyekt — har biri bitta variantga mos):
  - Muammolar ro'yxati · 6 / 6 ✓ — ostida to'rt qisqa qator («…» bilan): Tanaffusda telefonni quvvatlash uchun bo'sh rozetka topilmaydi. · To'garak qaysi xonada ekanini bilmay, o'quvchilar xonama-xona yurishadi. · Maktab oldida velosiped qo'yadigan joy yo'q — daraxtga bog'lab ketishadi. · Maydonga kelasiz — band; bo'sh vaqtni bilish uchun egasiga qo'ng'iroq qilish kerak.
  - MVP doskasi: Qilamiz · Keyin · Qilmaymiz (matnsiz kulrang yorliqlar; «Keyin»da uchta)
  - mahalla ko'chasi chizmasi: maktab, bekat, maydon va odamlar (matnsiz)
- Variantlar:
  - 9-Modulda yig'gan muammolarimdan
  - MVP'imning «Keyin» qutisidan
  - Atrofda yangi narsa kuzatib
- Javob (har qanday tanlovda, maqtovsiz): Uchalasi ham g'oya manbai bo'ladi. Mentor oltita g'oyasini shu uch joydan yig'di.
- Tanlangandan keyin: tanlangan obyekt ajralib turadi; maket ostida «Mentorning g'oyalari» qutisi chiqadi — uchala obyektdan yopiq kartalar navbat bilan uchib tushadi, son 0 / 6 dan 6 / 6 gacha o'sadi

## 2 · Nomdan g'oyaga
- Eyebrow: Tushuncha · g'oya
- Sarlavha: Ikki so'zli yozuvdan *nima qurishni* bilasizmi?
- Mentor: O'tgan modulda «Maydon»ning keyingi qadamini ikki so'z bilan yozgan edim: kartadagi savollarni birma-bir bosing.
- Bashorat (Avval o'zingiz belgilab ko'ring): Nima qurishni bilish uchun bu yozuvga nechta savol kerak? · 1 · 2 · 3
  - Tanlangach ixcham qator: savol · Taxminingiz: N
- Chapda — sahna: «Maydon» ilovasi kartasi (18:00 · 19:00 band · 20:00) va «Keyin» qutisi: to'lov · jamoa yig'ish · eslatma; «jamoa yig'ish» yorlig'i o'ngdagi karta nomiga uchadi (joyida ✓ qoladi)
- O'ngda — g'oya kartasi: nom **Jamoa yig'ish**, kulrang yorliq «Mentor misoli»; uch bo'sh qator, ichida savol-tugmalar: Qanday muammo? · Kim uchun? · Qanday yechim? (bashoratdan keyin faqat joriysi yoqiladi)
  1. Qanday muammo? → Muammo: o'yinga odam yetmaydi, kim kelishi noma'lum; ostida dalil: 9-Modul intervyusi: 5 kishidan 2 tasi «jamoaga odam yetmadi»
     - sahna: futbol maydoni — o'yinchilar va bo'sh o'rinlar, pufak «Kim keladi?»
  2. Kim uchun? → Kim uchun: mahalladagi o'yinchilar
     - sahna: maydon atrofida mahalla uylari, yorliq «o'yinchilar»
  3. Qanday yechim? → Yechim: o'yin e'loni va «Qo'shilaman»
     - sahna: telefon — e'lon «Bugun · 18:00», «8 / 10», tugma «Qo'shilaman» o'zi bir marta bosiladi → «9 / 10»; telefon ostida «chizma — hali qurilmagan»
  - Uch qator to'lgach: nom yonida yorliq «g'oya»; karta ostida: Uch savolga javob yozilgan yozuv — g'oya. «Jamoa yig'ish» esa uning nomi.
- Harakatsiz turganda: Kartadagi yoqilgan savolni bosing — qator nima bo'lishini ko'ring.
- Natija: «Taxminingiz to'g'ri chiqdi» yoki «Taxminingiz: N · haqiqatda: 3»
  - G'oya uch qismdan iborat: muammo, kim uchun va yechim.
- Tugma: Savollarni bosing (N/3) → Davom etish

Mentor ro'yxati (olti qator): Tanaffusda telefonni quvvatlash uchun bo'sh rozetka topilmaydi. · To'garak qaysi xonada ekanini bilmay, o'quvchilar xonama-xona yurishadi. · Maktab oldida velosiped qo'yadigan joy yo'q — daraxtga bog'lab ketishadi. · Maydonga kelasiz — band; bo'sh vaqtni bilish uchun egasiga qo'ng'iroq qilish kerak. · Oshxonada bugun nima borligini bilish uchun navbatga turib ko'rishadi. · Eski darsliklarni kimga berishni bilmay, o'quvchilar ularni uyda yillab saqlaydi. ## 8 · Oltita g'oya
- Eyebrow: Mustaqil ish
- Sarlavha: Oltita g'oyani *bittalab* yozing.
- Mentor: Avval manbani tanlang, keyin uch qatorni yozing: bugun g'oyalar baholanmaydi.
- Tepada — ro'yxat «G'oyalarim · n / 6»: yozilgan har g'oya bitta qator (yechim · manba · ✎); ✎ bosilsa o'sha g'oya katta kartada qayta ochiladi
- Markazda — katta g'oya kartasi:
  - Manba tugmalari: 9-Modul ro'yxati · «Keyin» qutisi · Yangi kuzatuv
    - 9-Modul ro'yxati: o'quvchining 9-Moduldagi muammolari ro'yxat bo'lib ochiladi (bosilgani Muammo qatoriga yoziladi, ishlatilgani ✓); topilmasa: Ro'yxat topilmadi — muammoni o'zingiz yozing.
    - «Keyin» qutisi: o'quvchining «Keyin» qutisidagi funksiyalar (bosilgani Yechim qatoriga yoziladi, ishlatilgani ✓); topilmasa: Qutingiz topilmadi — funksiyani o'zingiz yozing.
    - Yangi kuzatuv: Kim, qayerda, nimadan qiynaldi?
  - Uch qator (manba tanlangach yoziladi): Muammo — «Odamlar nimadan qiynaladi?» · Kim uchun — «Aynan qanday odamlar?» · Yechim — «Mahsulot nima qiladi?»
  - Tugmalar: Yordam · Saqlash
  - Yordam (tugmalar ostida ochiladi):
    - Manbalarni birma-bir oching: 9-Modul ro'yxatidagi muammoga yechim yozing, «Keyin» qutisidagi funksiyaga muammo toping, keyin bugun yo'lda ko'rganingizni eslang.
    - O'z MVP'ingizni davom ettirish ham g'oya — u boshqalar qatorida turadi.
- Tekshiruv yozuvlari (qator ostida):
  - Uch qatorni ham yozing.
  - Bu xohish — odam nimadan qiynalgani ko'rinmaydi.
  - Kim uchun aniqroq bo'lsin: qanday odamlar?
  - Mahsulot aynan nima qiladi? Bir gap bilan yozing.
  - Bu g'oya ro'yxatda bor — boshqasini yozing.
  - Bloklamaydigan tekshiruvdan keyin: Shunday qoldirsangiz — yana «Saqlash»ni bosing.
- «Saqlash»dan keyin karta ro'yxatga uchadi, hisoblagich o'sadi, yangi bo'sh karta chiqadi; 6 / 6 da karta yopiladi, ro'yxat butun enga — ikki ustun × 3
- Xulosa: G'oyalaringiz tayyor: N tasi 9-Modul ro'yxatidan, N tasi «Keyin» qutisidan, N tasi yangi kuzatuvdan. (0 bo'lgan bo'lak tushib qoladi)
- Tugma: Yana N ta g'oya yozing → Davom etish

## 10 · Kod yozish

    3. Sahifada uchta karta, har birida uch qator
  - Yordam (tugma):
    - Bitta yozuvdan boshlang: `return ["Muammo: " + goya.muammo, …];`. Yechim bo'sh bo'lsa (`goya.yechim === ""`), uning o'rniga «hali yo'q» qo'ying.
    - Eslatma (JavaScript darslaridan): massiv — ro'yxat · `+` — ikki matnni qo'shadi · `forEach` — ro'yxatdagi har element uchun bir marta ishlaydi.
- O'ng: Mentor — Tugmani bosing — kod oynasi ochiladi: kodni yozasiz va natijasini shu yerda ko'rasiz. · tugma «Kompilyatorni ochish» (kalit savolidan keyin) · ostida kod namunasi (nusxalanmaydi; to'g'ri javobdan keyin `muammo`, `kim`, `yechim` kalitlari bir lahza ajraladi)
- Nishon qatori: Birinchi urinishda to'g'ri bajarsangiz — nishon sizniki.
- Kod oynasi: sarlavha «app.js — qatorlar funksiyasini yakunlang» · fayllar `app.js`, `index.html`

```js
// Mentorning uchta yozuvi: muammo, kim uchun va yechim
const goyalar = [
  {
    muammo: "o'yinga odam yetmaydi, kim kelishi noma'lum",
    kim: "mahalladagi o'yinchilar",
    yechim: "o'yin e'loni va «Qo'shilaman»"
  },
  {
    muammo: "uy vazifasi chatlarda yo'qoladi",
    kim: "sinfdoshlar",
    yechim: "har fan bo'yicha vazifalar bir joyda"
  },
  {
    muammo: "eski darsligini kimga berishni bilmaydi, " +
      "u uyda yillab turadi",
    kim: "o'quvchilar",
    yechim: ""   // yechim hali yozilmagan
  }
];

function qatorlar(goya) {
  // uch qatorni ro'yxat qilib qaytaring:
  // "Muammo: …", "Kim uchun: …", "Yechim: …"
  return [];   // shu joyni siz yozasiz
}

// har yozuv — sahifada bitta karta (bu qism tayyor)
const joy = document.getElementById("goyalar");
goyalar.forEach(function (goya) {
  const karta = document.createElement("div");
  karta.className = "goya";
  qatorlar(goya).forEach(function (matn) {
    const p = document.createElement("p");
    p.textContent = matn;
    karta.appendChild(p);
  });
  joy.appendChild(karta);
});
```

