## 3-dars «Telegram Bot API + tugmalar» — Amaliyot · TelegramBotNest
- Sarlavha: **Repo'ni oling, botingizga menyu qo'shing.**

- Qadamlar:
  1. **Ochish** — GitHub'da `github.com/Azizbekcrypto/TelegramBotNest` → «Fork» (o'z nusxangiz). Terminalda:
     ```
     git clone https://github.com/{sizning login}/TelegramBotNest.git
     cd TelegramBotNest
     npm install
     ```
  2. **Token** — `.env.example` ni nusxalab `.env` qiling, `BOT_TOKEN=` ga @BotFather bergan tokenni yozing (chatga, skrinshotga emas). `npm run start:dev` → «Telegram bot ulandi». Telegramda `/start` → «Salom! Bot ishlayapti.»
  3. **Prompt** — Antigravity'da papkani oching, «Nusxalash», yuboring:
     > `src/api/telegram/telegram.service.ts` ga `/menu` buyrug'ini qo'sh: «Nima qilamiz?» va 2 ta inline tugma — **{1-tugma}**, **{2-tugma}**.
     > Har tugma uchun `bot.action` yoz, ichida `ctx.answerCbQuery()` chaqir. `bot.on('text')` fallback eng oxirida qolsin.
  4. **Telegramda tekshirish** — `/menu` → ikki tugma; bosganda javob keladi; boshqa matn → fallback.
- O'ng (namuna: AvtoPizza): /start → «Salom! Bot ishlayapti. Menyu uchun /menu ni bosing.» · /menu → «Nima qilamiz?» [🍕 Pitsa · ❓ Yordam] · «🍕 Pitsa» bosildi → «Pitsa tanlandi. Keyingi darsda buyurtma saqlanadi.»

## 4-dars «Stateful logika + PostgreSQL» — Amaliyot · users jadvali
- Sarlavha: **Botingiz ismni eslab qolsin: users jadvali.**
- Mentor: Darsda chizgan jadvalingiz endi haqiqiy bazaga tushadi — baza bepul va internetda; <b>«1 · Baza»</b>dan boshlang.
- Qadamlar:
  1. **Baza** — neon.tech → «Sign in with GitHub» → New project (nom: botingiz) → «Connection string» ni nusxalang → `.env` ga `DATABASE_URL=` (oxirida `?sslmode=require` qoladi).
  2. **Prompt** — Antigravity'ga:
     > `src/core/entity/user.entity.ts` yarat (`BaseEntity`'dan): `telegram_id` (bigint, unique), `ism` (nullable), `holat` (default 'yangi').
     > `src/infrastructure/database.module.ts` — TypeORM `forRoot` `config.DATABASE_URL` bilan, `autoLoadEntities`, `synchronize: true`; `AppModule` ga ula. `UserService` yoz: topOrYarat, ismQoy, holatQoy.
     > /start: bazada ismi bo'lsa «Yana salom, {ism}!», bo'lmasa `holat = 'ism_kutilmoqda'` va «Salom! Ismingiz nima?». Keyingi matn — ism saqlanadi, `holat = 'tayyor'`. /menu va tugmalar o'zgarmasin.
  3. **Ishga tushirish** — terminal xatosiz, «Telegram bot ulandi». Neon'da «Tables» → `users` jadvali o'zi paydo bo'ldi. Xato bo'lsa: «Shu xato chiqdi: {xato}. Tuzat.»
  4. **Telegramda tekshirish** — `/start` → «Ismingiz nima?» → ismingiz → «Xush kelibsiz, {ism}!» → botni qayta ishga tushiring → `/start` → «Yana salom, {ism}!» — holat bazada qoldi.
- O'ng (namuna): /start → «Salom! Ismingiz nima?» · «Aziz» → «Xush kelibsiz, Aziz! Endi sizni eslab qolaman.» · /start → «Yana salom, Aziz! Menyu uchun /menu ni bosing.»

## 6-dars «Bot ichida AI» — Amaliyot · Gemini
- Sarlavha: **Botingiz erkin savolga javob bersin: Gemini.**
- Mentor: System prompt'ni gemini.google.com'da sinab ko'rdingiz — endi u botning ichiga kiradi; <b>«1 · Kalit»</b>dan boshlang.
- Qadamlar:
  1. **Kalit** — aistudio.google.com → «Get API key» → Create → nusxalang → `.env` ga `GEMINI_API_KEY=` (chatga, skrinshotga emas).
  2. **Prompt** — qavsga o'z system prompt'ingizni qo'ying, «Nusxalash», Antigravity'ga:
     > `src/api/ai/system-prompt.ts` yarat: `SYSTEM_PROMPT` = «**{sen kimsan, qanday gapirasan, faqat nima haqida}**» + menyu/ma'lumotlaring.
     > `AiService` (`@google/genai`, model `gemini-2.5-flash`, `systemInstruction: SYSTEM_PROMPT`, temperature 0.4); kalit bo'lmasa `null` qaytarsin.
     > `bot.on('text')` da holat `tayyor` bo'lsa — AI javobi; `null` bo'lsa eski «Bu buyruqni bilmayman». Ism so'rash va menyu o'zgarmasin.
  3. **Ishga tushirish** — terminal xatosiz. Xato bo'lsa: «Shu xato chiqdi: {xato}. Tuzat.»
  4. **Telegramda tekshirish** — mavzuga oid savol → javob system prompt'ga mos; mavzudan tashqari («Ertaga ob-havo?») → chegarada qoladi; narx so'rang → o'z menyungiz bilan solishtiring (mos kelmasa — hallutsinatsiya, system prompt'ga menyuni aniqroq yozing).
- O'ng (namuna): «Achchiq bo'lmagani qaysi?» → «Margarita va Pishloqli achchiq emas. Margarita — 45 000 so'm. Tanlaysizmi? /menu» · «Ertaga ob-havo qanday?» → «Men faqat AvtoPizza haqida yordam beraman 🙂 Pitsa tanlaysizmi?»
- Yashil: AI botning ichida. Nima deyishini system prompt'ingiz belgilaydi.
- Zaxira: `git checkout -f dars-06-done`

✎ Eski 6 qadam (gemini.google.com chatida sinash, aistudio temperature) → kalit + kod; chat-sinov 4-qadamda botning o'zida.

## 10-dars «AI-agent yaratish» — Amaliyot · agent
- Sarlavha: **Agentga ikki asbob bering: qaysisini chaqiradi?**
- Mentor: Darsda ko'rgan `checkOrder` va `saveOrder` endi haqiqiy funksiya bo'ladi — chaqirishni agent o'zi hal qiladi; <b>«1 · Ochish»</b>dan boshlang.
- Qadamlar:
  1. **Ochish** — Antigravity'da `TelegramBotNest`, `npm run start:dev`. 6-dars kaliti `.env` da.
  2. **Prompt** — «Nusxalash», Antigravity'ga:
     > `AiService` ga Gemini «function calling» qo'sh. Ikki asbob: `checkOrder(taom, soni)` — taom `PITSALAR` da bormi, narxini qaytaradi; `saveOrder(taom, soni, manzil)` — `BuyurtmaService.yoz` bilan bazaga yozadi.
     > System prompt'ga: «MAQSAD: buyurtmani qabul qilib bazaga yozish. CHEGARA: taom borligini tekshirmasdan buyurtma yozilmasin.»
     > Model asbob chaqirsa — funksiyani bajar, natijani modelga qaytar, u keyingi qadamni o'zi tanlasin; oxirgi matnni mijozga yoz. Tugmalar va /start o'zgarmasin.
  3. **Ishga tushirish** — terminal xatosiz; konsolga har asbob chaqiruvi yozilsin (`checkOrder → …`, `saveOrder → …`). Xato bo'lsa: «Shu xato chiqdi: {xato}. Tuzat.»
  4. **Telegramda tekshirish** — «2 ta Pepperoni, Chilonzor 5» → konsolda avval `checkOrder`, keyin `saveOrder`; botda tasdiq; `/buyurtmalarim` da yangi qator. Keyin «3 ta Shaurma, Yunusobod» → `checkOrder` yo'q deydi, `saveOrder` chaqirilmaydi.
- O'ng (namuna): «2 ta Pepperoni, Chilonzor 5» → «Tekshirdim: Pepperoni bor. Buyurtma saqlandi: 2 × Pepperoni · Chilonzor 5 — 110 000 so'm.» · «3 ta Shaurma, Yunusobod» → «Shaurma menyuda yo'q — buyurtma yozilmadi. Pitsa tanlaysizmi?»
- Yashil: Keyingi qadamni agent tanladi, ishni siz yozgan asbob bajardi.
- Zaxira: `git checkout -f dars-10-done`

✎ Eski 4 qadam (aistudio'da Function calling sinovi, natijani qo'lda yozish) → haqiqiy asboblar botda. Repo `dars-10-done` shu ish bilan yoziladi.
