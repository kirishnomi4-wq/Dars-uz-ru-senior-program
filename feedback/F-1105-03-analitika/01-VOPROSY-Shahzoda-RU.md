## 1. «Нажал ли «Завершить урок»» (п. 10) — меняем подход

**Сейчас.** Результат уходит в LMS, когда студент нажимает «Завершить урок». Не нажал — LMS не знает, что урок пройден, и тест не открывается.

**Предлагаем** (обсудили с Абдулло): от кнопки больше ничего не зависит.
- Студент дошёл до последнего экрана урока → данные урока уходят **автоматически** (без Code Strike).
- Ментор закрыл Арену на живом уроке → **сразу** уходят результаты Code Strike.

Тогда флаг «нажал кнопку» не нужен. Вместо него по каждому студенту будет:
- `reached_end` — дошёл ли до последнего экрана, и время, когда дошёл;
- для тех, кто не дошёл, — до какого экрана дошёл (например, 14 из 20).

**Вопрос 1.** Подходит ли такая замена п. 10?
- а) да, флаг кнопки не нужен;
- б) нет, флаг всё равно нужен — напишите, для чего.

## 2. Постоянный id задания (п. 13)

**Сейчас.** id задания — это номер экрана: `s4`. Если в новой версии урока перед ним вставят экран, под `s4` окажется другое задание.

**Предлагаем.** У каждого задания свой постоянный ключ, который не зависит от номера экрана.
Например: `netlify-deploy:what-netlify-does`. Ключ не меняется, пока не меняется смысл задания.

**Вопрос 2а.** Данные до перехода останутся со старыми id (`s4`). Мы дадим таблицу «старый id → новый ключ» по каждому уроку. Этого достаточно?

**Вопрос 2б.** В задании поменяли только формулировку или порядок вариантов, а смысл тот же. Ключ:
- а) оставляем прежний — задание то же;
- б) даём новый — сравнивать до и после нельзя.
