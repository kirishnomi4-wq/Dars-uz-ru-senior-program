2. fixed sinfi (F-0929-91)

LMS sahifasi Tailwind CSS ishlatadi, unda .fixed { position: fixed } qoidasi bor. LMS darsni o'z sahifasining ichida chizadi (iframe yo'q), shuning uchun bu qoida darsga ham tegadi. Dars tuzatilgan qatorga aynan fixed degan sinf beradi. Natijada qator joyidan uzilib, brauzer oynasiga yopishib qoladi.

Bizning suratlarda shriftlar tarmoqsiz yuklangani uchun sarlavhalar boshqacha ko'rinadi. Bu farqning bugga aloqasi yo'q.

O'lchov (LMS CSS bilan / usiz)

  • HTML darsi: tuzatilgan qator position: fixed bo'ladi. 2-qator uning tagiga ko'tariladi (ikkalasi top: 393px), eni 281 → 334 px bo'lib qora qutidan chiqadi, quti balandligi 105 → 61 px ga tushadi.
  • PM darsi: .sxm-row da width: 100% bor. Qator fixed bo'lgach bu 100% ota-blokdan emas, butun oynadan hisoblanadi: eni 470 → 1366 px. Yashil chiziq shundan paydo bo'ladi.
  • LMS CSS'isiz ikkala ekran ham to'g'ri chiziladi.
Nega o'tgan safar tuzalmagan: xuddi shu bug 22.09 da React darsidan kelgan edi (F-0922-55, «kod qatorlari ustma-ust»). O'shanda ekran ochilib, xato qator bosilib tekshirilgan va natija «takrorlanmadi, skrinshot artefakti bo'lsa kerak» deb yopilgan. Bizning barcha tekshiruvlarimiz (page-audit, ru-walk, smoke-lms, Vercel QA saytlari) darsni LMS CSS'isiz ochadi, shuning uchun bug ularda hech qachon ko'rinmagan. Ya'ni u tuzatilmagan, «topilmadi» deb qolgan.
