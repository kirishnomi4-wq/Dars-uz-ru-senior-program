Nega baza kerak va ORM nima

Massiv — doskadagi bo‘r yozuv

Server o‘chib yonsa, hamma ma’lumot o‘chib ketadi. Haqiqiy do‘kon buyurtmalarni yo‘qotmasligi kerak — shuning uchun baza.

ORM — tarjimon

Siz TypeScript’da gapirasiz, baza SQL tilida. TypeORM o‘rtada tarjima qiladi — SQL yozish shart emas.

Entity = jadval qolipi

class Car { id; model; year }

→

car jadvali: id | model | year

Ikki hayotiy misol. Massiv — doskadagi bo‘r yozuv: dars tugab, doska artilsa, hammasi yo‘qoladi; baza esa daftar. ORM — tarjimon: siz repo.find() deysiz, TypeORM uni SELECT * FROM car ga o‘giradi. Pastdagi qator — Entity: class’ning har bir maydoni jadval ustuniga aylanadi. O‘rganishda SQLite (bitta fayl), haqiqiy loyihada PostgreSQL — kod deyarli o‘zgarmaydi.
