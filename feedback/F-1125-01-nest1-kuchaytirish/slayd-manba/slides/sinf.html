MENTOR UCHUN · SINFDA

Sinfda albatta uchraydigan 6 holat

1

/car → 404

Prefiks unutilgan: to‘g‘risi /api/v1/car

2

npm install uzoq yoki xato

2–5 daqiqa normal. Xato bo‘lsa — node -v, keyin node_modules’ni o‘chirib qayta

3

“Unable to connect to the database”

.env yo‘q yoki PostgreSQL ishlamayapti: cp .env.example .env

4

Port 3000 band

Oldingi server ochiq qolgan — yoping yoki boshqa port

5

“can’t resolve dependencies”

Javobni aytmang — xabarni 3 savol bilan birga o‘qing

6

“Nega Express emas?”

Bitta gap: katta loyihada tartib kerak, ichida o‘sha Express

Qoida: hammaning serveri ishlamaguncha oldinga o‘tmang — dars vaqtining eng ko‘pi shu yerda ketadi.

Saytdagi mentor darsidagi sinf holatlari asosida. Eng muhimi 3-holat: o‘quvchi loyihasi PostgreSQL’ga ulanadi; .env fayli bo‘lmasa yoki PostgreSQL ishlamasa, server ishga tushmaydi — terminaldagi ikkinchi satr sababni aytadi. .env’dagi superadmin blokini bo‘sh qoldirmaslikni ham ayting. 5-holatda javobni o‘zingiz aytmang: “qaysi klass? qaysi dependency? qaysi fayl?” deb so‘rang — o‘quvchi o‘zi topsin. 6-holatda metafora chalkashsa — lug‘atga qayting: oshpaz, ya’ni Service.
