AMALIYOT · 1-QADAM

Loyihani 3 ta buyruq bilan yaratamiz

Terminal
1. Nest CLI’ni o‘rnatishnpm i -g @nestjs/cli

Bir marta o‘rnatiladi — “nest” buyrug‘i paydo bo‘ladi

2. Yangi loyihanest new cars-api

Papka, fayllar va paketlarni o‘zi tayyorlaydi (npm va CommonJS’ni tanlang)

3. Ishga tushirishnpm run start:dev

Faylni saqlasangiz — server o‘zi qayta yonadi

Brauzerda localhost:3000 oching — “Hello World!” chiqsa, hammasi to‘g‘ri.

Terminal animatsiyasida uchta buyruq ketma-ket yoziladi, o‘ngda esa hozir qaysi qadam ekanligi yonadi. Darsda buni haqiqiy terminalda birga bajaring. Tipik muammolar: 1) Windows’da “nest is not recognized” — terminalni yopib qayta oching yoki npx @nestjs/cli new cars-api deb yozing; 2) paket menejerini so‘raganda strelka bilan npm’ni tanlang; NestJS 12 CLI CommonJS yoki ESM deb so‘raydi — CommonJS’ni tanlang, darsdagi kod va keyingi Jest darslari shunga mos; 3) Node versiyasi 22 dan past bo‘lsa — node -v bilan tekshiring. Hamma Hello World’ni ko‘rmaguncha keyingi slaydga o‘tmang.
