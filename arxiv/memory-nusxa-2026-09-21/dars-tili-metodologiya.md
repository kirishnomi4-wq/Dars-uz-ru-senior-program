**Metodologiya qoidalari:**
- Har blok o'quvchi HARAKATI bilan tugaydi (o'qish emas); passiv slaydlar bashorat/mikro-tanlov bilan jonlantiriladi.
- Induktiv tartib: SAVOL → hayotiy misol → qoida → keys → o'z loyihasi.
- Test halolligi: bitta himoyalanadigan-to'g'ri variant; uzunlik-tell yo'q (grapheme ≤1.4×); sanoq-moslik (matndagi son = UI'dagi son).
- Test reveal bilan tugaydi — keyin qo'shimcha majburiy qadam TAQIQ (foydalanuvchi jonli sinovda rad etgan).
- Nishonlar faqat REAL harakatga; «hammasini qildim — badge chiqmadi» = nuqson.
- Preview/kompilyator 3 holatda (bo'sh/yarim/to'liq) singan ko'rinmasin.
